# 今日菜谱设计

沿用现有森林绿、浅绿与暖黄，宋体标题和微软雅黑正文。第三个并列标签放在“逛菜谱”右侧，避免压缩菜谱浏览网格；手机保持三个入口可见。

今日菜谱由未安排大厅和早餐、中餐、晚餐组成。大厅在上，桌面三餐三列，手机纵向排列。所有原有菜谱入口提供独立的“加入今日菜谱”按钮；卡片的查看按钮与加入按钮为同级控件，避免嵌套交互。

新菜先进入大厅，同一道菜只占一个位置。用户选择餐次即可移动，也能回到大厅、查看做法、单独移出或清空计划。收藏与抽签历史保持独立。

计划最多保存1000个有效菜品ID及所属区域，使用现有浏览器存储的独立todayPlan字段。刷新和同源标签同步保留计划，不按日期自动清空；无法保存时告知仅本次有效。

验证包括模型去重和非法数据、全部加入入口、餐次移动、浏览位置、刷新及跨标签、原有功能与320/390/1440像素布局。
