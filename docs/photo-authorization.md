# 照片来源与授权记录

本项目用户已在当前任务会话中两次明确确认拥有美食天下照片的转载授权，并授权本项目使用相关图片。本文件记录该用户声明，供本项目素材接入与发布检查引用；不表示美食天下照片已采用开放许可，也不转让原作者权利。

适用范围为本项目中实际取得并经逐图视觉核对的美食天下菜品照片。每张图片在 `data/photos.json` 中保留原菜谱页 `source`、原作者 `credit`、图片直链 `imageSource` 和加工说明 `changes`。只有对应菜品经过视觉核对时才将 `exact` 设为 `true`。

这些图片统一使用以下记录：

- `license`：`经用户授权转载；原作者保留权利`
- `authorizationRef`：`docs/photo-authorization.md`
- 不填写不存在的公开 `licenseUrl`，不标注为 CC、Unlicense 或项目代码的 MIT 许可。

2026-09-14，用户进一步明确：冷门菜没有对应成品图时，可以使用能够找到的图片补充。本项目优先使用同名成品照；相近菜品照片须设为 `exact: false`，记录实际源菜名 `sourceTitle` 和差异说明 `referenceNote`，在卡片及详情中明确展示“参考图”。这不改变菜谱的名称、食材或做法。

本记录不扩大用户确认的授权范围，不授权项目使用者将照片另行分发到其他项目。下载清单和逐图来源另行保留；页面无法访问或下载失败不计为取得素材。

2026-09-14，用户进一步允许使用其他网站的对应或相似菜品实拍，并明确指定下厨房（www.xiachufang.com、mip.xiachufang.com）与豆果美食（www.douguo.com）。选择时优先核对菜名、主要食材与成品形态。其他来源逐项保留实际出处和署名，未发现开放许可时标注“原作者保留权利；来源页未声明开放许可”，不套用美食天下的授权记录，也不虚构 CC 许可。
