# 888 道菜库扩展计划

## 目标

保留随机 1～10 道、全菜系排除小吃、冰箱选菜与收藏功能，将菜库扩展到 888 道真实且去重的菜谱。

分类采用两层独立维度：八大菜系、家常菜、地方小吃；以及热菜、凉菜、汤羹、主食、小吃、甜品、烘焙、饮品。地方归属没有把握的常见菜归家常菜，不为凑数伪造地方菜。

## 页面方向

借鉴美食天下的分类导航与菜品图片网格；保留本项目绿色视觉和以随机选菜为主的简洁首页。增加可搜索、按分类浏览的菜库入口，每次只显示一页，避免一次创建 888 张卡片。手机不使用覆盖内容的固定操作栏。

## 菜谱与图片

新增配方使用原创家常参考说明；为每道菜记录具体主料、用量、调味、步骤、烹饪时间和关键提示。保留已有稳定 id，让收藏继续有效。

用户指定美食天下作为图片来源，并在本任务中明确确认已取得网站转载授权，可以使用照片。后续接入照片时保留原站来源和作者，第三方照片不并入项目 MIT 许可。

原站网页的自动读取返回 403，公开图片搜索无可用结果。用户指定 ImageAssistant 扩展后已检查：当前工具中没有此插件；浏览器控制仅连接 Codex 内置浏览器，尝试连接 Chrome 返回“Browser is not available: chrome”。因此图片接入等待可访问的授权素材下载链接，或用户使用扩展导出的本地素材。此限制属于工具与素材访问，不是再次要求转载许可。

## 验证

核对总数恰好 888、id/规范菜名去重、分类覆盖、每条配方字段、随机数量及排除小吃逻辑、冰箱匹配；复测实际点击遮挡、菜库分页、手机与桌面布局。图片仅按已确认可用的来源和授权发布，不把参考图称为对应成品图。
