# v2.0.1 布局修复与九道菜补充

手机首屏的固定抽签栏覆盖了数量按钮。390×844 下，底栏位于 y=763..832，而第二、三行数量按钮处于该区域；点击“随机十道”的中心点会命中底栏按钮。旧检查只确认底栏在视口内，没有检测其是否遮挡其他按钮。

## 修改

- 手机抽签栏回到正常文档流，放在菜谱后，不再悬浮覆盖筛选、菜单或冰箱内容。
- 手机上显示结果区的重抽按钮，标题与操作区分行排列；底部多余留白一并调整。
- 数量按钮补齐 1～10，增加“随机九道菜”可访问名称，手机数量按钮高度至少 44px。
- 浏览器检查加入实际点击位置检测，避免“元素存在却被遮挡”漏检。

## 本地验证

- `npm test`：24 项全部通过。
- `scripts/browser-check.cjs`：14 组交互检查通过，覆盖随机、冰箱、收藏、离线与存储异常。
- `scripts/layout-check.cjs`：320、360、375、390、430、600、700、701、720、768、1024、1440px 全部通过。首屏可见筛选控件的中心点击命中自身；点击九道菜真实坐标后得到 9 道不同菜品；页面无横向溢出。
- 独立检查了全部 168 道菜在窄屏及断点附近的标题、图片说明与收藏弹窗，未发现额外的裁切或横向溢出。

线上入口：[吃啥呢 v2.0.1](https://jokerlixing.github.io/daily-dish/?v=2.0.1)。查询参数用于区别上一版本的浏览器缓存。
