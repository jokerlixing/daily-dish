# 初版验证记录（v1 归档）

此文件记录首次交付时的验证结果，保留作历史参考。当前升级版结果见 `upgrade-verification.md`。

- 交付：根目录 `index.html`，约 169 KB，内置 HTML、CSS、JavaScript、SVG 插画和完整菜谱。
- 内容：104 条，八大菜系各 10 条、24 条小吃；ID 与菜名均唯一，每条含配料数量、人数、时间、步骤和贴士。
- `npm test`：7 项核心测试通过，包括数据完整性、组合筛选、整轮无重复、换候选池、手动查看收藏后的即时防重复及独立 HTML 打包。
- 浏览器：本机 Chrome，通过 Playwright 检查 11 组场景，运行时错误为 0。
- 视口：320×740、390×844、768×1024、1440×1050 均无横向溢出；手机抽签按钮保持可见。
- 实际交互：八大菜系与小吃筛选、关键词与食材搜索、非辣/素菜/时长组合、空结果恢复、收藏刷新持久化/查看/删除、历史、食材与步骤勾选、弹窗 Escape 关闭。
- 离线：以 `file://` 打开并禁用网络，仍可显示完整菜谱、抽签和切换分类，无外部网络请求。
- 异常：禁用浏览器存储时仍可抽签和在当前会话收藏；给出无法持久保存的提示。
- 动效：遵循减少动态效果设置；随机动画可被新筛选或搜索取消，不会提交旧结果。
- 视觉：已查看桌面和手机截图，关键食材用量和步骤文本已提高对比度和字号。

复现浏览器测试需安装 Playwright，或通过 `PLAYWRIGHT_MODULE` 指向已有安装，并可用 `BROWSER_EXE` 指定 Chrome 可执行文件，然后运行 `node scripts/browser-check.cjs`。网页本身没有这些依赖。

范围：菜谱为家常参考，未逐道试做；移动端为浏览器视口验证，未操作实体手机。当前预览运行在本地，尚未部署公网；Git 仓库没有配置远程，因此没有 GitHub 推送。
