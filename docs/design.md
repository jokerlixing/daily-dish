# 吃啥呢 · 初版设计记录（v1 归档）

此文件记录最初的 104 道菜与插画版本。当前 168 道菜、多道菜单、冰箱匹配和实拍图片版本见根目录 README。

目标：电脑和手机浏览器内，一次点击得到菜名、食材和完整家常做法。涵盖八大菜系和地方小吃，无账号、无模型服务依赖。

方案比较：纯 HTML 可双击运行且能离线带走；前端框架需要构建环境；在线 AI 生成需要接口并可能产生不稳定食谱。本项目采用原生 HTML/CSS/JavaScript，源文件分离维护，构建成不依赖外部资源的单一 index.html。

视觉：纸白 #f7f9f4、墨绿 #183f32、叶绿 #527b4b、橙黄 #eea743、浅绿 #e8efdf、正文 #263b32。标题用系统中文宋体栈，操作和正文用系统黑体栈。签名元素为带筷子和手绘食物的盘子示意图；不是给不同菜伪装成真实照片。桌面用宽幅菜单卡和两栏做法，手机改为单栏与底部抽签按钮。

内容：104 条原创家常简化做法，由 80 条八大菜系菜谱、24 条地方小吃组成。传统来源/归属参考见 data/sources-*.md。菜谱不是专业或唯一标准版本。

交互：菜系、非辣、素食、时长筛选；按筛选候选池洗牌抽签，轮完前不重复；收藏和最近抽到的菜在本机浏览器保存；食材和步骤可勾选；可搜索菜名/食材；空结果提供清除筛选。存储失效仍可用。

验证：数据结构、数量、分类、过滤、无重复抽签等逻辑；在真实浏览器验证桌面与 390/320px 手机宽度、无横向溢出、收藏持久化、抽签、筛选和键盘操作。运行 file:// 和 HTTP 两种打开方式。
